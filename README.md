# 思辨島｜AI 倫理情境桌遊

給國中小資訊科技課堂與教師研習使用的分組口說活動。每組 3–4 人，不需登入、不輸入姓名；每位學習者都能先形成自己的想法，再傾聽差異、調整觀點並共同提出做法。

## 建議玩法

1. 第一回合「大家一起想同一題」，練習每個人先想、再輪流說。
2. 第二回合「每組探索不同題」，輸入相同活動代碼與不同組號，優先取得不同情境。
3. 第三回合「我們自己三選一」，由小組共同決定真正想深入的情境。
4. 每回合結束後回想剛才使用過的思考方法，帶走小組紀錄並和全班分享。
