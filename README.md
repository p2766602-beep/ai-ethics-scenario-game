# 思辨島｜AI 倫理情境桌遊

給國中小資訊科技教師與學生使用的分組口說活動。每組 3–4 人，不需登入、不輸入姓名，以情境卡引導學生說明理由、傾聽差異並提出改善做法。

## 建議玩法

1. 第一回合使用「全班同一題」，由教師示範討論方法。
2. 第二回合使用「各組隨機題」，輸入相同活動代碼與不同組號，題目會優先不重複。
3. 第三回合使用「學生三選一」，讓小組共同決定想深入討論的情境。
4. 每回合完成後勾選實際使用過的思辨視角，下載小組討論紀錄並進行全班分享。

- 教師體驗版：6 張
- 國中版：10 張
- 國小版：8 張
